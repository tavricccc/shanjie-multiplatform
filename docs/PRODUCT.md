# 善解 Windows

## Platform
Windows 10 / 11 原生 TSF 輸入法。

## 使用目的
將善解上游注音引擎接入 Windows，支援標準與倚天鍵盤、整句轉換、候選選擇。
設定頁保留 Windows 原生控制項；候選僅橫向膠囊，與設定共用淺／深色或跟隨 Windows 的主題偏好，維持不透明實色底與細邊線，高對比優先使用系統色。優先低資源與日常操作，模型只提供最新固定配對。
中英混打在正文組字區保留英文原始按鍵，下方以同一原生候選窗顯示藍底白字注音提示；聲調完成後轉中文，Enter 保留原文。簡拼／免聲調功能與設定已移除。
Windows 操作與上游操作以個人 INI profile 切換；Windows 預設遵循微軟注音常用鍵位。上游子模組保持乾淨，Windows 核心擴充透過平台覆蓋套入建置副本。

## 維護界線
Windows 產品邏輯為 Rust；設定的 C#／XAML 保留 WinUI 控制項與綁定。引擎演算法與資料來源由固定版本上游負責。
平台覆蓋檔只接入建置副本，子模組保持乾淨。不上網傳送輸入內容。

## 尚未驗證
真實應用程式相容性、簽章發佈、ARM64。
