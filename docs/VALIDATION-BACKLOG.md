使用者已確認 0.12.2 修訂產物（原交付標記 r2）的實機驗收通過，詳見 [版本驗證紀錄](releases/VERIFICATION-0.12.2.md)。不重列 r2 已通過的 Shift、首次輸入、雙 Ctrl 與浮層取消待辦。Excel 儲存格反白取詞取消需求，不作為待修或待驗收項目。

一般唯讀內容加詞已於 0.13.0 pre-release 實作；隔離測試與真正宿主驗收分開記錄，見 [0.13.0 驗證紀錄](releases/VERIFICATION-0.13.0.md)。以下原功能矩陣不以舊版「拒絕唯讀」政策限制新需求。

## 輸入、設定與資料

- [ ] 數字混打延伸：Windows 注音順序與兩者並用的 13／14／16／17、連續數字、數字接中文及有效注音；不同宿主／配置重複與長時間測試。
- [ ] 浮層延伸：跟隨系統、明確淺／深色與高對比切換；多螢幕、高 DPI、邊緣定位；收錄比對、不同讀音、快速 Enter 等待比對、保存失敗保留草稿、PowerToys 等快捷鍵衝突及替代快捷鍵。Office 範圍不含已取消的 Excel 儲存格取詞。
- [ ] 設定唯一視窗：右鍵與 settings.cmd 同時啟動、最小化恢復、關閉重開、不同版本／使用者／工作階段；未儲存草稿保留。
- [ ] 混打容錯：刻意英文＋中文、縮寫、型號、輸入延遲與誤更正案例；原始候選可選回，不改宿主已提交文字。
- [ ] 模型管理延伸：下載中關閉／重開、手動放入／移走／修復配套、有組字時切換、兩宿主更新及升級保留 Models／字典／學習；比較成績須用當次版本與固定配置重測，不引用歷史 dev302 結果作新證據。
- [ ] 大小寫與配置：三種混打模式的 Caps Lock／Shift＋Caps Lock、Shift 英文段、中文混排、倚天與未安裝配置反灰／核心防護，以及切換模式先提交文字。
- [ ] 句中提交：游標在句中、固定多字詞跨切點、候選後提交及後段繼續編輯／取消；舊設定缺值與操作預設符合各自政策。
- [ ] 宿主延伸：Thorium／AyuGram 等中的數字、標點、未完成讀音、原始按鍵候選、注音開關與候選；日後輸入路徑變更時回歸 cmd 的 adb／xyz 單次提交。測試欄位不得送出訊息。
- [ ] AppContainer／長時間：Windows Terminal、設定 App、開始功能表搜尋與其他沙箱宿主的設定讀取、管道、候選及長時間輸入；記錄實際 DLL／核心版本。
- [ ] 候選與配置：直式候選、畫面邊緣、縮放、標準／倚天逐鍵標點、匯入操作預設、忙碌／斷線與焦點切換。
