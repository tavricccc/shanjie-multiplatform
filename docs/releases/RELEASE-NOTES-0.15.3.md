# 善解輸入法 0.15.3

以 0.15.2 為基礎的本機測試修正版，尚未 push 或公開發布。保留 0.15.2 的個人詞典載入與組字收尾修正。

## 修正

- **「哎呦」變成空白加數字與「優」**：標準注音啟用上游判斷時，尚未結束的數字／注音串也算待處理輸入；`9 空白 u . 空白` 的 Space 會交給核心確認第一聲，不再被 Windows 前端提早當成字面空白。
- **「設定」變成 `社/4`**：「兩者並用」下，數字串轉回注音後保留完整按鍵順序，讓 `gk42u/4` 能繼續完成「設定」，不丟掉「ㄉㄧ」的前半讀音。
- **數字鍵暫時顯示兩次**：數字串接手按鍵後重新取得輸出，避免原始按鍵與數字緩衝區同時顯示同一個 `9`。

不需要沿用 0.15.2 的暫時繞過設定。若之前改用「注音順序自動判斷（Windows 版）」，可在「中英混打與切換」改回原本使用的方式，並按主視窗「儲存」。本版不會替使用者自動改選。

## 個人資料與驗收

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。上游維持 v0.6.1，內建模型組不變。

安裝後重新開啟使用輸入法的應用程式，先以原本的「兩者並用」或「上游判斷」確認「哎呦」與「設定」，再確認一般數字與日常混打。自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用驗收。
