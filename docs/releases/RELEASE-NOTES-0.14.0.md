# 善解輸入法 0.14.0

同步善解上游 v0.6.0，內建模型改為上游 App 的完整一組，並加入上游的新功能設定。

## 新功能

- **新內建模型**：通語 SJ-LM-7、辨類 SJ-WC-6、承接 SJ-KN-2、書面與聊天兩個連文 SJ-CX-2、會意 SJ-SR-7、常談 SJ-CL-2。
- **上游功能的設定**：資訊與 AI 詞包、模糊輸入（ㄣ／ㄥ、ㄓ／ㄗ、ㄔ／ㄘ、ㄕ／ㄙ、鄰鍵打錯）、語意校正開關與強度、依按鍵順序判斷英文、中英文之間自動加空格、依 App 自動切換聊天／書面（聊天程式清單可自訂）。
- **語意校正改在背景執行**：按鍵不等模型，打字停頓時套用結果。
- **「取得其他模型」**：名稱、狀態與評測備註分行顯示並自動換行，另顯示清單的更新時間（臺灣時間）。

## 更新時的設定與模型

- 舊設定檔會改寫成新格式，原檔留一份 `profile.ini.schema<N>.bak` 備份。
- 原本使用舊內建 model-v6＋classes-v5 的設定改用新內建。
- 手動選用的下載模型：本版仍支援就保留選擇，每次開啟設定提示已有新的內建模型；本版不再支援就改回內建，並在設定提示一次。

## 修正

- 下載或重新掃描模型後，切換設定分類再回「一般」，模型下拉選單變成空白。
- 線上清單有一個本版無法驗證的配套時，整份清單都無法取得；現在只略過該配套。
- 模糊輸入選到容錯候選時出現內部錯誤。

## 其他

- 「標點保留未完成的注音」改為選項，新設定檔預設關閉（與上游相同），舊設定檔維持開啟。
- 只提供單檔安裝程式 `Shanjie-Windows-Setup.exe`，不再附 zip。
- Linux 版停止維護，停在 0.12.1。

## 安裝

下載 `Shanjie-Windows-Setup.exe` 執行，可直接從 0.12.2 或 0.13.x 更新；個人詞庫、學習與下載的模型會沿用。
