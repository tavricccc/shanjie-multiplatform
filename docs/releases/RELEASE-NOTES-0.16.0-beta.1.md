# 善解輸入法 0.16.0-beta.1

Windows 測試版（pre-release）。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 變更

- **中英混打方式改為單選**：關閉、自動判斷或原鍵混打三選一，移除「兩者並用」。原本兩種混打模式都開啟的設定檔，升級後會自動改為「原鍵混打」。
- **快速設定改為從頭重寫設定檔**：快速設定完成時以全新的設定檔取代原有的，舊設定檔先備份為 `profile.ini.before-quick-setup.bak`；需要舊設定時可從備份取回。
- 快速設定逐步引導、含轉場動畫；閱讀面板預設關閉。
- 移除 Big5 相關選項。
- 上游 repo 已無法存取，原始碼子模組與模型下載改由鏡像 `tavricccc/shanjie-upstream-backup` 提供；模型檔名與 SHA-256 不變。

## 個人資料與回報

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。已開啟的應用程式要重新開啟才會用到新版。

自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用。遇到問題請回報：善解版本、Windows 版本、在哪個應用程式發生、按了哪些鍵、預期和實際的結果。
