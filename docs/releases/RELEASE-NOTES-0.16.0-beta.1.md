# 善解輸入法 0.16.0-beta.1

Windows 測試版（pre-release）。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 升級前要知道

- **舊版無法再下載模型**：上游 repo 已無法存取，0.16.0-beta.1 之前的版本下載或更新模型都會失敗。這版起，原始碼子模組與模型改由鏡像 `tavricccc/shanjie-upstream-backup` 提供；模型檔名與 SHA-256 都不變。
- **中英混打改為單選，移除「兩者並用」**：選項是關閉、上游自動判斷、原鍵混打三選一。兩種都開著的設定檔，升級後會改成「原鍵混打」。
- **快速設定完成時會整份重寫設定檔**：以範本加上你的選擇寫成全新的設定檔，舊檔先備份為 `profile.ini.before-quick-setup.bak`。會從舊檔帶過來的有模型、詞包、聊天 App 清單、詞典和鍵盤配置。按略過或關掉時不會改動任何設定。

## 新功能：快速設定

- 第一次安裝、升級，或從設定重新開啟時出現，一頁一個問題：範本、空白鍵、選字時的 → / Tab、中英混打、Shift 切換、記住選字、組字面板，最後可以試打。
- 有換頁、選取、示範和完成動畫；Windows 關閉動畫時直接到位，高對比時改用系統色。
- 解除安裝時會一併清掉快速設定的紀錄。

## 預設值與行為

- **兩個範本預設都用上游混打**，組字面板預設關閉；沒有候選字或提示時不顯示面板。選了原鍵混打時，組字面板固定開啟。
- **善解範本對齊上游預設**：空白鍵選字、Shift 切換中英、學習、Caps Lock 英文、刪除候選預設開啟。設定檔裡明確寫過的值會保留。
- **Tab 依範本不同**：
  - 微軟注音風格：Tab 和 → 一樣，預設展開候選，候選列對齊微軟注音。
  - 善解：Tab 關閉候選、送出文字，並把 Tab 交給 App，和上游相同。
- **選字框只保留直式**，設定與快速設定裡的方向選項移除。
- **移除 Big5**：Big5 候選過濾和 Big5 內碼輸入都拿掉了。

## 外觀

- 設定和快速設定的狀態列改成玻璃主題，依提示類型帶淡色、使用新圖示，有淡入淡出效果。
- 沒有候選字時，組字面板的寬度會貼合文字，不再撐成固定寬度。

## 修正

- 只開一種混打、但設定檔缺少另一個設定時，載入後會被補成兩種都開，存檔後就寫進設定檔。現在缺少的那個一律視為關閉。
- 存檔時寫回舊的 schema 版本號，導致下次載入又遷移一次，把使用者明確關掉的設定重設回預設值。
- 多個 App 同時第一次連線時，核心還在載入就會回報忙碌，約 1 秒後放棄。現在會等核心載入完成。
- 打包時會一併產生安裝檔的 `.sha256`。
