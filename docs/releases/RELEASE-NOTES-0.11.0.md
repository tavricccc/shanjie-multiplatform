# 善解 0.11.0 測試版（Windows／Linux）

日期：2026-10-20。上游更新到善解 v0.4.7 Release。

## 新增

- **數字層**：開啟上游英文詞表（或兩者並用）且使用標準注音時，數字列的鍵可直接打出數字，與上游相同。
- **ACG 詞包**：動漫遊戲用詞，預設開啟，可在「預測、詞庫與學習」頁關閉；屬個人設定，載入操作預設不會改動。
- **上游新功能**：重選凍結、新詞學習、預測列。
- **英文詞表**：改用上游的 82,730 字清單，取代原本的 Rime Easy English 子集。

## 修復

- 有個人詞庫時，常見專有名詞層（`names.tsv`、`names-add.tsv`）沒有載入。
- 有個人詞庫或開第二個核心後，數字層沒有作用。
- 數字串進行中按 `Ctrl+\` 顯示「ㄅ、」，現在和上游一樣是「1、」。
- 未完成讀音後打標點再按 Shift＋字母，標點被排到英文後面。
- 忘記學習詞時寫入失敗會留下暫存檔。

## 仍與上游不同

- 中英混打（含數字層）預設關閉；上游 App 預設開啟。
- 中英文自動加空格、各 App 個別設定、語意修正 Windows 沒有。

## 資料與相容性

設定 schema 不變，個人詞庫、學習與已下載的模型沿用。安裝包新增 `digits.tsv` 與 `packs/acg-add.tsv`，打包檢查要求這些檔案存在。

已通過編譯、核心與上游回歸（含 v0.4.7 新增的數字、新詞、重選測試）、x64／x86 背景 TSF harness、設定介面離屏 render 與打包校驗。尚未安裝到真實系統驗收，見 [TODO](../../TODO.md)。
