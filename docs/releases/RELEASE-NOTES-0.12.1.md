# 善解輸入法 0.12.1 測試版（Windows／Linux）

日期：2026-10-20。上游維持善解 v0.4.7 Release，核心、詞庫與內建模型未變。

## 新增

- **單檔安裝程式**：Release 附上 `Shanjie-Windows-Setup.exe`，下載後直接雙擊即可，不必先解壓縮。它先校驗內含的安裝包，只解開安裝畫面本身就開啟 0.12.0 的 WinUI 安裝畫面，模型與資料在選擇鍵盤時於背景解開（按下安裝時若還沒完成會先顯示進度）；畫面關閉後自動刪除暫存。檔案比 zip 小約 16%（以系統內建的 LZMS 壓縮，不需額外元件）。

## 優化

- **完整解除安裝，不再使用 `.deleted_files`**：程式檔案直接刪除，不再把整個安裝目錄搬到 `.deleted_files` 留著。仍被開啟中 App 載入的 `Shanjie.dll` 等檔案只留下那幾個，由一次性的系統排程 `ShanjieCleanup` 在下次登入或開機時刪除，完成後排程自行移除（也同時登記 Windows 的重新開機刪除）。選擇移除個人資料時直接刪除。舊版留下的 `.deleted_files` 副本會一併清掉。
- **更新不再累積舊版本**：以前舊版本只要有一個 DLL 被 App 占用，整個 300 MB 的資料夾都要等重新開機才刪；現在其餘檔案立即刪除，只留下使用中的那幾個，重新登入後清掉。
- **Linux**：`uninstall.sh --delete-user-data` 與設定程式的清除、覆蓋同樣直接刪除，不再搬到 `.deleted_files`。
- **安裝包根目錄精簡**：`install.cmd`、`uninstall.cmd`、`重新選擇鍵盤.cmd`、`settings.cmd`、`apply-*.cmd` 與 PowerShell 腳本移到 `scripts\`，根目錄只留「安裝善解.exe」與說明文件。更換鍵盤改為重新執行安裝程式。

## 修正

- **名稱與圖示**：「已安裝的應用程式」原本沒有圖示（指向的圖示檔沒有放進安裝包），現在改用設定程式本身內嵌的善解圖示。名稱由「善解 Windows」改為「善解輸入法」，安裝畫面、設定的關於頁、Linux 設定與 Release 標題一致。
- **解除安裝當掉**：移除輸入法註冊時，COM 物件在 COM 結束後才釋放，可能讓解除安裝當掉，留下已取消註冊、但程式檔案還在的半套安裝。現在先釋放再結束。
- **只剩善解一種輸入法**：如果某個語言（通常是中文（台灣））只裝了善解，移除後 Windows 會把整個語言拿掉，回復也無法完成。解除安裝現在會在要求系統管理員權限前先檢查，提示先到「設定 > 時間與語言 > 語言與地區」加入其他輸入法（例如微軟注音），不做任何變更。
- **進度動畫**：安裝與解除安裝畫面的進行中步驟改用 WinUI 原生的 ProgressRing。

## 相容性

- `Shanjie-Windows.zip` 照常提供，內容與單檔安裝程式相同；命令列腳本的用法不變，只是位置改到 `scripts\`。安裝目錄的 `settings.cmd`、`uninstall.cmd` 不變。
- 設定 schema 不變，個人詞庫、學習與已下載的模型沿用。Linux 版只有上述刪除方式的變更。
- 安裝程式與 DLL 目前沒有數位簽章，從瀏覽器下載後 Windows SmartScreen 可能先跳出警告。

已通過 Rust 單元測試（含單檔安裝包的打包／解開／損壞偵測，解除安裝刪除與使用中檔案、清除排程定義的 Task Scheduler 驗證）、安裝畫面的離屏 render 與打包校驗，並實際執行單檔安裝程式：約 5 秒開啟安裝畫面、其餘檔案隨後在背景解完且通過打包校驗，解開途中取消與關閉畫面後都確認暫存已刪除。
