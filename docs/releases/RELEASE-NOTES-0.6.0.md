# 善解 Windows 0.6.0

日期：2026-10-14。本版依 0.6.0 計畫擴充按鍵自訂、操作預設分享、直式候選與亂序注音，並補 WinUI／Windows Terminal 等沉浸式宿主的相容註冊。上游 pin、model-v5／classes-v3 與內建詞庫不變；0.5.0–0.5.3 的常駐核心、復原與安裝修正沿用。

## 逐鍵標點開關

「Shift＋符號」與「直接按鍵」兩列中文標點，改為每個符號各自一個開關（設定頁「標點符號」）。例如可以只讓 `[` `]` 輸入「」，而 `\` 仍輸出原本的反斜線；以前開「直接按括號等鍵」會一併把 `\` 變成頓號。

profile 升到 schema 6：新增 `[punctuation] shift_<名稱>`、`plain_<名稱>`，原本的 `shift_punctuation`、`plain_punctuation` 會依舊值展開成逐鍵設定後移除，所以升級後的行為不變。舊檔先備份成 `profile.ini.schema5.bak`。

## 操作預設匯入／匯出

「一般」頁新增「匯入操作預設…」與「匯出目前操作…」。匯出的 `.ini` 只包含按鍵、選字與預測等操作；詞句偏好、個人詞庫、學習、鍵盤配置與外觀不會寫進檔案。匯入時逐項比對預設檔：只接受已知鍵，旗標只能是 0／1，選項類（如 Esc、選字位置、候選排列）只接受合法值，有任何一項無效就整檔拒絕。匯入成功的預設會存到 `%LOCALAPPDATA%\Shanjie\presets\`，之後可以在「載入操作預設」直接選。匯入後先成為未儲存草稿，按儲存才套用。

## 直式候選

「外觀 → 候選排列」可選橫向（善解膠囊列）或直式（微軟注音）。直式是一列一個候選，每頁最多九項，滑鼠點選、淺色／深色主題都支援。

## 注音不照順序輸入

一般組字本來就會把聲母、介音、韻母放進各自的位置；這次是中英混打模式也能接受亂序輸入，例如 `0d4` 和 `d04` 都會輸出「看」。為了不讓英文單字被誤認為注音，只有第一碼是數字或符號的時候才放寬順序；第一碼是英文字母的仍要照「聲母→介音→韻母」，而且同一個位置都不能重複。

## 設定頁重新分類

分成：一般（操作預設、輸入、語言模型）、切換與快捷鍵、標點符號、組字與提交、選字、外觀、預測詞庫與學習、關於。

## WinUI／Windows Terminal

TSF 註冊新增 `GUID_TFCAT_TIPCAP_IMMERSIVESUPPORT` 與 `GUID_TFCAT_TIPCAP_COMLESS`，沉浸式／WinUI 宿主依這兩個類別決定是否列出輸入法。若宿主是 AppContainer 沙箱：profile 改用使用者真正的資料夾，讀不到時用預設值輸入，不會整個停用；核心管道 DACL 加上 `ALL APPLICATION PACKAGES` 的讀寫權限；沙箱程序不會自行啟動或檢查核心，改用登入時啟動的常駐核心。**這些修正都還沒在實際安裝的 Windows Terminal 中驗收**，原因判斷來自程式碼比對，列在 TODO。

需要重新安裝（重新註冊）新的類別才會生效。
