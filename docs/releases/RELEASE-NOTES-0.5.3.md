# 善解 Windows 0.5.3

日期：2026-10-13。本版修正由 0.5.1 雙鍵盤升級至 0.5.2、選擇單一鍵盤時的安裝失敗，並補齊安裝錯誤紀錄。輸入、常駐核心、個人詞庫與學習功能沿用 0.5.2；上游 pin、model-v5／classes-v3 與內建詞庫不變，私人詞典不進入發佈包。

## 單一鍵盤與 Windows 語言清單

0.5.2 的舊式清單通知沒有同步 Windows 現行的使用者語言清單，留下未選擇配置的項目，最終校驗因此失敗。新版透過 Windows 內建的 International 介面讀取、同步與核對清單，只保留選定的標準注音或倚天；其他語言、輸入法相對順序、拼字檢查及手寫選項保留。原預設輸入法若指向被移除的善解配置，改為選定配置；其他預設不變。

安裝入口維持 install.cmd 與原生 manager。管理程式會在背景呼叫系統內建 Windows PowerShell 5.1，不須另外安裝 PowerShell 7；輔助程式編入執行檔，請求內容以 JSON 資料傳遞。若偵測到其他語言設定在安裝期間被外部變更，回報錯誤並保留紀錄，不覆寫那些變更。

## 權限回復

0.5.2 回復登錄資料時，舊 API 會清掉部分安全描述元的自動繼承旗標；首次失敗紀錄與目前狀態比對共找到 47 個項目，其擁有者、群組、存取規則與資料值相同。新版略過未改變的權限，並使用保留繼承語意的 API 回復具有自動繼承的項目。

若安裝目錄保留 0.5.2 的失敗 checkpoint，新版安裝時會比對本程式的 COM、TSF 及解除安裝機碼，只修復「與舊紀錄完全相同，僅缺自動繼承旗標」的項目。變更前、預定變更與結果均有紀錄；不匯入舊資料值，不修復規則或擁有者已改變的項目。成功修復後的狀態成為本次安裝的回復基準。

## 安裝紀錄

主要紀錄位於 `%ProgramFiles%\Shanjie\.installer-recovery\<本次識別碼>\`：

- `error.txt`：先保存最初失敗的階段及原因，後續回復錯誤不會覆蓋它。
- `events.jsonl`：版本、時間、各階段開始／成功／失敗與回復結果。
- `checkpoint.json`、`expected-language-list.json`、`validation.json`：安裝前狀態、預期與實際完整清單，以及兩架構註冊／路徑。
- `rollback-errors.txt`：回復未完成項目；`completed.txt` 區分提交成功或回復完成。
- 有舊版旗標修復時，另存 `permission-repair-before.json` 與 `permission-repair-plan.json`。

初始化、套件校驗或 UAC 等較早期的失敗，另於 `%LOCALAPPDATA%\Shanjie\installer-logs\<本次識別碼>\` 保存錯誤。對話框會附上可用紀錄的完整位置。紀錄含本機路徑與權限資訊，回報問題時只需提供相關錯誤段落。

## 驗證界線

兩架構 release 建置、隔離交易故障測試、真正 Windows 登錄測試機碼的部分寫入／重建／繼承回復，以及 International 物件轉換均已驗證；隔離模式明確拒絕修改目前語言清單。細節見 [VERIFICATION.md](../../VERIFICATION.md)。本輪未執行實際 install.cmd、未修改目前安裝、47 個真實項目的權限或個人輸入設定。0.5.1 雙鍵盤至單一配置的實際升級仍列於 [TODO.md](../../TODO.md) 驗收。
