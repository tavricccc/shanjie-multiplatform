# 善解輸入法 0.13.0 pre-release（Windows）

**這是預先發布的測試版，尚未完成使用者實際安裝與日常使用驗收。建議一般使用者先使用上一個正式版本 [0.12.2](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.12.2)。** 自動測試通過不代表所有應用程式、登入與顯示環境均已驗收；0.12.2 繼續保留為最新正式版。

## 本版變更

- 修復「Windows 注音順序」及「兩者並用」混打下，`r3／r4／r6／r7` 及其他不完整字母讀音後的數字消失。無法形成有效讀音時保留原字母與數字；`su3 → 你`、`r3su3 → r3你` 等有效中文轉換照常運作。
- 新增登入使用者工作階段的加詞輔助程式。對支援選取文字介面的唯讀內容，反白 1–32 個漢字後連按兩下同一側 Ctrl，可在詞旁開啟加詞浮層。提供一組建議讀音供確認／修改，沿用收錄比對與個人詞庫合併保存。來源未提供選取介面時無法取詞；Excel 儲存格取詞依既定範圍不處理。
- 輔助程式以一般登入使用者權限執行，不新增 SYSTEM 服務。只讀取本次前景視窗的選取內容，不讀整篇文件、不使用剪貼簿，排除密碼欄位。取詞逾時會回收自己的工作程序；來源失焦、關閉或反白改變時丟棄過期結果。浮層沒有獨立工作列視窗，關閉與滑鼠取消沿用非同步生命週期保護。
- 新增第二版線上模型清單與下載備註。技術驗證通過的模型均可選用；評測退步、尚未評測、預覽資料、效能或使用差異以備註呈現，選用前可選「仍然選用／取消」。取消保留原模型與其他未儲存設定；下載完成不會自動切換模型，設定須儲存才生效。已下載配套保留備註供離線查看。
- 支援目前上游已知格式的 KN、trigram、語意重排模型及獨立口語主模型，依各檔案的實際格式、來源雜湊及配對資料驗證；不因標籤名稱不同而排除。同格式後續資料版本可由自動維護流程驗證與上架。新格式、新附件種類或新核心能力仍須更新程式後才能使用。
- 部署 GitHub Actions 模型清單維護流程：每日臺灣時間 09:23 檢查官方上游，完成 x64／x86 原生載入、基本輸入提交及固定公開測試後，原子更新獨立資料分支。準確率分數不作為下架門檻；網路與測試故障保留上一份有效資料。例行模型資料更新不必重建安裝包。

## 資料、相容與測試範圍

- 安裝包繼續只內建 model-v6＋classes-v5；其他配套由使用者自行選擇下載。這次沒有把個人詞庫或學習資料放進內建資料、模型或發行包，更新繼續沿用原個人資料。
- 0.12.2 繼續使用原有 format:1 清單；需要新能力及備註介面的配套由 0.13.0 的 format:2 端點提供，避免舊程式忽略新配套或備註。
- 已進行兩架構編譯、隔離輸入回歸、模型原生探測、故障測試及自建唯讀／密碼／取消視窗測試。完整證據與實機待驗範圍見 [驗證紀錄](VERIFICATION-0.13.0.md)。
- **尚未在使用者電腦安裝本版，也尚未驗收 Codex 回覆區、一般瀏覽器、Win+R 等真正宿主的新版取詞、登入後單例及多螢幕 DPI。** 支援選取介面是取詞前提，不能保證所有唯讀畫面均可使用。
- 本次為 Windows pre-release；Linux 程式未加入本版 Windows 輔助程式與設定介面功能。

模型維護與故障處理見 [維運說明](../MODEL-CATALOG-MAINTENANCE.md)。本次未修改 repo 根目錄的 README.md。
