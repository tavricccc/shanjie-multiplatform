# 善解輸入法 0.16.1-beta.1

日期：2026-11-24。這次 Windows 測試版同步原作者善解 v0.9.0 與其後的 main（`bddb22b0`），更新會意模型，新增口語讀音、中英混合詞與英文預測，並在密碼等私密欄位暫停學習。

本版通過 GitHub 上的輕量 CI，各 PR 也附了開發者本機的測試結果，還沒有收到安裝後的日常使用回報。希望維持正式版本的使用者，可繼續使用 [0.16.0](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.16.0)。

## 新增功能

- **三聲變調**：照實際唸法輸入的變調（如「眨眼」）也能打出原本的三聲詞；「這／那／哪」接量詞的合音讀法也能辨識。口語輕聲與疊字陰平（如「厲害」、「熱騰騰」）同樣可用。「變調與口語讀音」開關位於「模糊輸入」，與上游一樣預設開啟。
- **英文或注音自動比較**：覆打成英文時，在收尾鍵比較英文與注音，選出較合理的結果；Esc 可把一段英文改回注音。
- **會意 SJ-SR-10-31M**：內建語意模型升級並參考更長的前文；校正耗時比舊模型長，立即按 Enter 時可能先送出校正前的文字。
- **中英混合詞與英文預測**：可用字母加注音輸入「K書」等詞，英文補全列在首格顯示 Tab 提示。
- **私密欄位暫停學習**：密碼、PIN、私密輸入欄位與常見密碼管理程式中不讀前文、不學習選字；組字照常。
- **學習儲存提示**：選字學習無法寫入時，候選窗、語言列與設定頁會提示。
- **英文段提示開關**：可在設定關閉英文段開著時的「空白：英文斷開」提示，預設開啟。

## 穩定性修正

- 單獨輸入反引號後按 Enter 會送出反引號並結束組字。
- 右側候選補回預測列的讀音範圍與原數字候選。
- 語意校正改在較低優先度執行，未重新解碼的按鍵不再中斷校正。
- 修正候選窗動畫最後一格沒有畫出就停止的問題。
- 修正設定頁底部被空白狀態列截斷，「更新通道」看不完整。
- 自訂強調色與預設藍相同時，選取文字維持白字。

## 更新通道

- 選測試版通道也會收到正式版。沒有手動切換時，通道跟隨目前安裝的版本。

## 與上游不同之處

- 英文段提示接在組字列之後，上游為獨立一行；Windows 另提供關閉開關。
- 模型清單與附件優先從原作者倉庫讀取，讀取失敗才改用鏡像。

- 私密欄位判斷採 Windows 輸入範圍、原生密碼欄與程式名稱。
- 常駐核心啟動時會將自己排除於 Windows 錯誤報告，避免傾印含有輸入內容；解除安裝時移除。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不含任何私人詞典。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

若降回舊版，新增的英文預測學習紀錄會在舊版下次改寫學習檔時移除，其他紀錄不受影響。

本次為 Windows 測試版，支援 x64 Windows 與 32 位元應用程式。
