# 善解輸入法 0.16.0-beta.2

日期：2026-11-10。這次 Windows 測試版帶來更多外觀選擇與純注音輸出，並改善中英混打、模型選擇及設定視窗的穩定性。

本版已完成隔離測試，並收到整合版安裝後初步使用正常的回報，仍待更長時間的日常使用確認。希望維持正式版本的使用者，可繼續使用 [0.15.3](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.15.3)。

## 新增功能

- **讓善解更像你的 Windows**：選字、設定與加詞浮層的強調色，可跟隨 Windows 系統色，或選擇自己喜歡的顏色。深色模式新增純黑背景選項，選取文字會依底色調整，維持清楚易讀。
- **動畫由你決定**：可選擇跟隨系統、強制開啟或關閉善解動畫。即使 Windows 關閉動畫，也能單獨保留善解的動態效果，不影響其他程式。
- **直接輸入注音文**：在「組字與提交」開啟「純注音輸出」，即可輸入注音符號與聲調，不轉換成漢字。支援標準及倚天注音，預設關閉；關閉後恢復原本的輸入方式。
- **注音符號更容易選**：標準注音的數字與部分符號候選，新增對應的注音與聲調選項，需要輸入「ㄅ」或「ˇ」時更方便。

## 使用上的改善

- **數字編輯更可靠**：改善 `99.9%`、`1%` 等數字接符號時的順序與內容保存。單按 `1` 再按左方向鍵時，會保留數字並移到它的左邊，後續仍可繼續插字、刪除與提交。
- **混打更順手**：改善快速輸入時注音按鍵先後顛倒，以及 Shift 英文接中文的判斷，減少部分情況下出現錯誤英文或遺失按鍵。
- **選字與學習更一致**：展開選字後，上下鍵沿同一欄移動；改善右側候選、改選與分段提交的處理，減少把取消或刪除的內容誤記住。
- **符號選擇更完整**：補齊更多全半形標點、括號、引號與箭頭候選，並改善反引號符號輸入。
- **模型選單更好讀**：長名稱會自動換行，清單可上下捲動；切換設定頁面或重新掃描模型時，保留原本的選擇。
- **更新內建會意模型**：內建會意更新為 SJ-SR-8-15M。改善舊來源下載模型的辨識，升級後可繼續使用原有配套，不必因來源改為鏡像而重新下載。
- **關於頁新增貢獻者介紹**：可查看參與者資訊與連結，將游標停在名字上即可展開介紹。

## 穩定性修正

- 修正部分情況下，從工作列開啟設定會出現「XAML parsing failed」而無法使用的問題；啟動失敗時也提供更完整的錯誤紀錄，方便後續排查。
- 修正設定首次開啟時，已停用的相依選項沒有立即反灰。停用期間保留原先的選擇，重新啟用後可繼續沿用。
- 加強雙 Ctrl 加詞快捷鍵的狀態恢復，改善特定操作後可能無法觸發的情況。
- 改善更新檔的發布流程，完成建置、測試與檔案校驗後才公開，降低下載到不完整版本的機會。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不包含任何私人詞典。

若在快速設定中選用範本，設定會依範本重新建立，舊設定會先備份。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

本次為 Windows 測試版，支援 x64 Windows 與 32 位元應用程式。Excel 儲存格反白加詞仍不列入支援範圍；其他程式的加詞功能，也需要來源提供可讀取的反白文字。長時間使用、重新登入及多螢幕環境仍持續驗收。
