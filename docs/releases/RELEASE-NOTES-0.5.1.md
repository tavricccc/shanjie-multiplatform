# 善解 Windows 0.5.1

日期：2026-10-12。上游固定 `368eebc426981852094d8c0c49b8b0618143bd2b`，模型為 model-v5／classes-v3。

## 多行個人詞庫修正

設定 → 個人詞庫中，每行格式正確的詞條現在可以一次貼上、儲存及重載。舊版可儲存單行，但 WinUI 文字框使用 CR 換行時，原生儲存 parser 把多行當成一行，因而錯誤提示格式不符。

儲存入口現在接受 LF、CRLF、CR 與混合換行，仍以 UTF-8、Tab 分隔欄位及 LF 換行寫入。字詞與注音音節數量、讀音格式，以及有限非正數分數等驗證維持原有規則；內容雜湊命名與個人資料位置維持原有方式。

保留 0.5.0 的登入後常駐核心、Ctrl + 單引號頓號及中英混打 Caps Lock 修正；本版沒有更新上游、模型或內建詞庫。

## 驗證與資料界線

- Windows crate 4 項單元測試通過，包含新增的換行與無效格式檢查。
- x64／x86 原生 DLL 各通過 LF、CRLF、CR 全量詞典保存及重載，共 6 組；三種換行產生相同內容。
- 實際 WinUI 個人詞庫文字框的三種換行、草稿綁定、保存及重載通過；另以外部 117 筆有效詞條完成隔離保存與重載。錯誤詞條仍拒絕。
- 外部詞典只作測試。個人詞條、測試輸出與私人比對報告均未納入程式、內建資料、安裝包或原始碼 bundle。

本版未安裝至目前系統；使用者設定與個人學習資料未變更。實際前景 App、登入與解除安裝驗收仍需安裝後進行。詳細紀錄見 `../../VERIFICATION.md`。
