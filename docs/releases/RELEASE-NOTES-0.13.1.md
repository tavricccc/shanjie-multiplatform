# 善解輸入法 0.13.1（Windows pre-release）

**這是修正版的預先發行版本。建議一般使用者先使用正式版 0.12.2；願意協助測試者再安裝本版。**

0.13.0 使用者回報除本次兩項問題外，日常使用正常。本版修復高 DPI 加詞浮層與 Microsoft Store 核心連線問題，保留 0.13.0 的混打、唯讀取詞及線上模型功能；不把先前版本的使用回報當作本版已安裝驗收。

## 修復內容

- **加詞浮層太大、出現在來源視窗下方**：輔助程式在建立視窗前啟用 PerMonitorV2，以浮層本身的 DPI 只縮放一次。有效選取期間，浮層以不搶焦點的方式顯示於來源上方，選取位置移動時重新定位。來源失焦、關閉或選取改變即關閉；保留同程序 owner 與非同步取消，避免回到舊的跨程序焦點重入路徑。失敗提示的尺寸、字體與顯示層級一併修正。
- **Microsoft Store 中文輸入顯示核心無回應**：受限宿主可讀取核心檔案，但 DOS 路徑解析會遭 Windows 拒絕。本版以同一開啟檔案的 NT 路徑與內容建立連線身分；啟動程序仍使用 Windows 執行路徑，伺服器、狀態查詢與舊核心回收一致。保留使用者、工作階段、版本及伺服器驗證；不提升權限、不放寬使用者資料權限。
- **使用者資料位置一致**：核心、TSF 與設定視窗共用 Windows 已知資料夾判定，避免其他程式傳入的環境變數將核心與詞庫導向封裝資料夾或 systemprofile。正常的個人詞庫、學習、設定及下載模型沿用；其他位置的舊副本保留，不自動合併覆寫。
- **失敗紀錄**：即使預載失敗被恢復機制接住，也會留下連線階段、版本、Windows 錯誤代碼等必要資訊。每階段節流、檔案大小限制約 256 KiB，不記錄按鍵、組字、候選、反白文字、字典或資料路徑。一般程序位於 `%TEMP%\shanjie-tsf.log`；Store 位於其封裝可寫入的 Temp 資料夾。

## GitHub 維護

兩個工作流程的官方 Actions 更新至 Node.js 24，固定完整 commit SHA。使用 GitHub 託管 runner，最低需求為 2.327.1；未啟用 checkout 的不安全 PR 選項，保留關閉憑證持久化。新版 artifact 沿用 archive 模式與原本的目錄契約。

模型清單維持先原生驗證再原子更新資料分支，準確率退步仍保留可選及 UI 備註。release 工作流程手動預設僅建置驗證；重跑既有版本不修改原 Release、頻道或資產，也不使用覆寫上傳。

## 安裝與驗收

可使用單檔安裝程式，或解壓縮 zip 後執行「安裝善解.exe」。更新仍沿用既有個人資料；私人字典與學習資料不放入安裝包。

安裝後請優先確認：

1. Microsoft Store 搜尋欄的中文組字、Enter 提交與 Esc 取消，以及設定／一般桌面程式輸入。
2. 記事本、Win+R、AyuGram、Codex 的雙 Ctrl 加詞：尺寸、層級、讀音鍵、滑鼠取消、Esc、重開及來源失焦。
3. 有多螢幕時跨 DPI 移動與畫面邊緣；重新登入後預載與個人詞庫／學習沿用。

Excel 儲存格反白取詞依既定範圍不處理。建置與隔離測試證據、實機驗收界線見 [驗證紀錄](https://github.com/tavricccc/shanjie-multiplatform/blob/867f147/docs/releases/VERIFICATION-0.13.1.md)。
