# Windows 0.12.2 驗證紀錄

日期：2026-10-24。來源基底為 0.12.1 的 `a9767ab1308b378fd1a660af88ee0a54cd6dbf2d`，包含本版 Shift、短暫文件交接、加詞取詞、雙 Ctrl 節奏與浮層生命週期修正。上游固定 `a639e8ada773327a1ddf06b0f96b4c32db67d6c2`，內建模型及共享資料格式未變。

## 建置與測試

- Windows Rust release：x64／x86，使用鎖定相依及離線快取，未啟用 `input-diagnostics`。WinUI Release x64 版本為 `0.12.2.0`，隨附 DLL 與發行 x64 DLL 相同。
- 選用診斷功能另以 `cargo check --features input-diagnostics --lib` 驗證，不混入一般發行 DLL。既有 COM 匯出與測試宣告警告保留，不宣稱完成線上相依弱點稽核。

| 測試 | x64 | x86 | 內容 |
| --- | --- | --- | --- |
| 修飾鍵與選取單元測試 | 5/5 | 5/5 | Shift／Ctrl 代理、雙 Ctrl 節奏、重複通知與組合鍵保護；漢字／UTF-16 限制、背景 UIA 取詞與密碼／唯讀保護 |
| TSF 相容性 | 18/18 | 18/18 | 短暫同文件交接保留 `123`、真正換文件／逾時收尾、`adb` 單次提交、延後取詞及過期選取防護 |
| 加詞浮層生命週期 | 15/15 | 15/15 | 滑鼠／Esc 取消、同步焦點重入、連點、拖出放開、加入儲存、快速重開、延遲結果、宿主銷毀、TSF 停用及淺深色 |

測試使用真原生視窗與 TSF context。生命週期 harness 建立私有桌面但不切換至該桌面，不向使用者前景程式送鍵；使用工作目錄內隔離設定、停用學習及公開詞例「回家」。背景核心限定為未安裝的測試 payload，依同一程序 handle 核對路徑後才清理，不停止日常核心。

重跑方式：對應架構的 MSVC／SDK 環境編譯 `tests/compat_0122.cpp` 或 `tests/popup_lifecycle.cpp`，以 `scripts/verify-compat-0122.ps1` 指定未安裝 payload、harness 與全新輸出目錄；生命週期以 `-Cases` 選取對應 15 項，原有相容性省略 `-Cases` 執行 18 項。

## 修正定位與證據界線

修正前的隔離對照在焦點隱藏時同步回送 TSF 失焦回呼，可重現 `panic_already_borrowed`；宿主銷毀情境另找到停用清理的重入借用。關閉改為先標記再延後派送，原生視窗與回呼共同持有狀態；清理先取出資源、釋放狀態借用，再解除訂閱與銷毀。按鈕只接受對應點擊通知，關閉通知與背景結果須對應目前的浮層與請求。

上述是條件明確的隔離重現，並不是已取得 Explorer 實機例外堆疊。使用者曾回報 shell 非預期結束，當時沒有 dump 可確認完全相同的原因；2026-10-24 使用者已回報修訂產物的實機驗收通過，Win+R 滑鼠取消的待辦據此結案，歷史堆疊的證據界線不變。

原始建置、測試及重現紀錄保留本機，公開版本只定義單一 0.12.2；既有證據檔名不作為額外版本發行。

## 發行與未驗證範圍

原始發行程式已完成兩架構測試及原生 package 校驗；ZIP 全項目、單檔安裝包壓縮區與解碼後檔案均經 SHA-256 檢查。本次發布僅整理文件及重封裝，程式檔須與已驗證產物雜湊相同；不含私人 profile／詞庫／學習、本機 TODO、備份或診斷程式。

## 使用者實機驗收與範圍調整（2026-10-24）

使用者明確回報：「對於 r2，實機驗收除了 excel 取詞都成功，但這個不會處理，所以可以移除 excel 的取詞需求」。因此本次 0.12.2 修訂範圍的 Shift、開始輸入首鍵、雙 Ctrl 加詞及浮層取消穩定性驗收結案；Excel 儲存格反白取詞取消需求，不列未完成修復或後續驗收。沒有將取消需求記成修復通過。

已實施功能的完整跨宿主／DPI／長時間及安裝故障矩陣另移至 [待辦](../../TODO.md)，未逐項確認者仍保留未確認狀態；不以本次版本驗收概括所有情境。一般唯讀內容取詞是新的功能規劃，見 [唯讀取詞設計](../design/readonly-word-capture.md)，尚未實作或實機測試。

本輪只更新需求與文件紀錄，沒有執行安裝、變更註冊、提升權限或重啟 Explorer。
