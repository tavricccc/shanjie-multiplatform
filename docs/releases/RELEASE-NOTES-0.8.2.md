# 善解 Windows 0.8.2

日期：2026-10-15。小改版，沿用 0.8.0 的上游與 model-v6＋classes-v4。

## 讀音列

- 候選窗上方的讀音列顯示完整句子。游標移進句子中間時，目前要選的字以藍色文字標示；`[candidates] anchor=right` 標游標右邊的字，`left` 標左邊的字。
- 混打模式輸入注音時，讀音列不再只顯示注音：整句保留，打到一半的注音換掉對應的英文按鍵、插在游標處並標藍；應用程式本身的輸入框仍顯示英文按鍵。
- 引擎在混打提示的候選列多傳一項輸入的英文按鍵（`platform/smart_input_windows.rs`），讀音列用它找出要換掉的範圍。
