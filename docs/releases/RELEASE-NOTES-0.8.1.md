# 善解 Windows 0.8.1

日期：2026-10-15。小改版，沿用 0.8.0 的上游與 model-v6＋classes-v4。

## 候選窗讀音列標示目前的字

選字打整句後按左方向鍵，引擎會移動游標，但候選窗上方的讀音列原本整句同色，看不出現在要選哪個字。現在游標在句子中間時，游標前一個字（引擎列出候選的那個字）會以強調色底標出；游標在句尾時不標。

- 改動在 `windows/src/candidate.rs` 的讀音列繪製，以 DirectWrite 的 `HitTestTextRange` 取得該字範圍。
- 按左鍵不會自動展開候選，仍須按下鍵（行為沒有改動）。
