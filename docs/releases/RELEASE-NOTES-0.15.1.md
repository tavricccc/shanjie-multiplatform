# 善解輸入法 0.15.1

同步善解上游 v0.6.1，介面改為更現代的風格，設定裡可以直接檢查並安裝更新。包含 0.15.0 測試版的全部變更。

## 已知問題（後續確認）

- **個人詞典可能使核心載入失敗**：個人詞典與內建詞層、姓名或詞包出現相同的「讀音＋字詞」時，0.15.1 會將合法重複項目視為載入錯誤，常駐核心可能在預載後退出。使用者會看到「核心暫時無法回應／正在重試」，部分宿主也可能因等待核心而沒有回應。這是版本回歸，不是詞典格式輸入錯誤，無須刪除個人詞條；**0.15.2 已修復**。
- **組字收尾失敗後可能永久卡住**：若收尾的編輯要求、寫入或結束組字失敗，可能持續顯示「正在完成上一段組字」，後續無法輸入，切換到其他輸入法再切回同一實例也可能無法恢復。**0.15.2 已補上重試與過期回呼防護**。

0.15.2 為測試版，另有已知混打問題及暫時設定方式；更新前請先閱讀 [0.15.2 版本說明](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.15.2)。若暫時沿用 0.15.1，可先切換其他輸入法；重開受影響的應用程式可能解除卡住的組字實例，但無法修正字典重複導致的核心載入失敗。請保留個人詞庫及學習資料。

## 新功能

- **檢查更新**：設定的「關於」會查比目前新的正式版與測試版（pre-release），兩者都有時自己選一個；下載後核對 SHA-256，按「安裝更新」自動安裝並重新開啟設定。個人詞庫、學習與設定都會保留。
- **更現代的介面**：設定與安裝視窗改為毛玻璃（可調濃度）；選字框換成同一套外觀與動畫；有安裝 Noto Sans 時全部介面使用它。
- **選字框動畫**：顯示中改變大小或位置（候選變長、中英混打提示列、游標移動）時滑到新位置，不再跳動。
- **上游 v0.6.1 中英混打**：改為上游的「變回按鍵」判斷，新增「重打同一個位置算英文」「快打時鍵序顛倒不當英文」；新設定檔「依按鍵順序判斷英文」預設開。
- **經典台詞詞包**（預設關）。

## 修正

- 更新後，更新前就開著的程式一打字就沒有回應並當掉。現在舊版仍被程式載入時會保留整個舊版資料夾，登出或重新開機後才清除。
- 選字框只有注音時字太小、留白太大且偏上；候選與安裝程式單選項的文字改為垂直置中。

## 與上游不同

- 既有設定檔的「依按鍵順序判斷英文」維持原值（通常是關）。
- 移除「打字時直接顯示英文字母」，與上游相同。
- 上游的「依 App 單按 Shift 切換中英」沒有移植，Windows 保留自己的 Shift 切換。

## 0.15.1 相對 0.15.0

- 檢查更新也列出比目前新的測試版（pre-release）；正式版與測試版都有時，可以改選另一個。

## 安裝

下載 `Shanjie-Windows-Setup.exe` 執行，可直接從 0.14.0 或 0.15.0 更新；0.15.0 也可在設定「關於」按「下載更新」。從 0.14.0 以前更新時，已經開著的程式若打字異常，請關掉重開。
