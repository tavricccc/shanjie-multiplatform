# 善解輸入法 0.16.0

Windows 正式版，發布日期：2026-11-19。以 0.15.3 為基礎，整合 0.16.0-beta.1 到 beta.4 的內容：同步原作者善解 v0.8.0 的核心與完整詞庫，新增快速設定、外觀選項與純注音輸出，並修正發布前驗收找到的問題。

## 升級前要知道

- **中英混打改為單選**：選項是關閉、上游自動判斷、原鍵混打三選一，移除「兩者並用」。原本兩種都開的設定檔，升級後會改成「原鍵混打」。
- **英文覆寫改為預設關閉**，與上游一致。沒有儲存過這個設定的使用者，更新後會變成關閉；明確儲存過的值會保留。
- **快速設定完成時會重寫設定檔**：舊檔先備份為 `profile.ini.before-quick-setup.bak`，並帶過模型、詞包、聊天 App 清單、詞典和鍵盤配置。按略過或關掉時不會改動任何設定。
- **選字框只保留直式**，並移除 Big5 候選過濾與 Big5 內碼輸入。

## 新增功能

- **同步善解 v0.8.0**：採用逐鍵讀音解碼、多音字詞頻、句首單字學習與異體字排序。新增美妝與保養、迷因與直播兩組詞包，與上游一樣預設開啟；也可以直接打出 ChatGPT、CP值等中英混合詞。
- **快速設定**：第一次安裝、升級或從設定重新開啟時出現，一頁一個問題，最後可以試打。
- **外觀與動畫**：強調色可跟隨 Windows 或自訂，深色模式可用純黑背景；善解的動畫可單獨開啟或關閉。
- **純注音輸出**：在「組字與提交」開啟後，直接輸入注音符號與聲調，支援標準及倚天注音，預設關閉。
- **詞包切換不打斷輸入**：新的詞庫在背景建立，目前的組字結束後才換上。
- **更多符號候選**：減號、斜線、星號可選箭頭、刪節號與 `※` 等符號。

## 使用上的改善

- 組字時參考同一行游標前的文字（最多 64 字），候選更貼近上下文；不儲存這段文字。
- 快打時鍵序顛倒或聲調太早按下，也能還原成正確讀音；Shift 英文接中文更順。
- 改善數字接符號的編輯、展開選字的移動，以及改選與分段提交的學習。
- 長句會標出正在選字的詞段。

## 穩定性修正

- 修正部分 Windows 10 上設定與安裝視窗出現「不支援此種介面」而無法開啟的問題，無法使用玻璃效果時改為純色背景（#114）。
- 修正切換鍵盤配置或純注音後，緊接著按下的第一個鍵仍沿用舊設定的問題。
- 修正 PowerPoint 文字方塊無法組字、右 Shift 無法切換中英。
- 修正從工作列開啟設定偶爾出現「XAML parsing failed」，以及停用的相依選項首次開啟沒有反灰。
- 多個 App 同時第一次連線時，會等核心載入完成，不再約 1 秒後放棄。

## 與上游不同之處

- Windows 保留單按 Shift 切換，兩個範本仍預設開啟。
- 模型清單與附件優先從原作者倉庫讀取，讀取失敗才改用鏡像；檔名與 SHA-256 不變。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不含任何私人詞典。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

支援 x64 Windows 與 32 位元應用程式。Excel 儲存格反白加詞不在支援範圍；其他程式的加詞，需要來源提供可讀取的反白文字。
