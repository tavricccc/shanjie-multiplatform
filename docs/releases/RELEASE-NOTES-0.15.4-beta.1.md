# 善解輸入法 0.15.4-beta.1

Windows 測試版（pre-release），以 0.15.3 為基礎。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 輸入

- **單按數字鍵顯示數字**：中英混打選「上游判斷」或「兩者並用」時，單按數字鍵會直接顯示數字，按 Enter 送出數字（原本 `1` 會顯示並送出 ㄅ）。
- **仍可繼續組字**：後面繼續打字時仍可組成注音，例如 `184` 還是「爸」；`3.14`、`2026` 也能正常輸入。
- **完整音節維持原樣**：`5`、`8`、`0` 本身是完整音節，按空白仍會轉成中文，例如 `5` 加空白是「之」；`1`、`2` 加空白則顯示數字加空格。畫面是 `1` 時按 ↓，仍會開 ㄅ 的清單。
- **數字鍵盤**：沒有候選字時輸入數字，不再當注音；有候選字時仍可用來選字。中文全形模式下輸出半形數字。
- **→ 右鍵換下一頁候選**：新增選項，預設關閉。開啟後 → 翻頁，↓ 仍是移到下一個候選字；不套用在聯想列。

## 修正

- **重開設定後模型變回內建**：安裝並選擇下載模型、儲存後，重開設定視窗不再顯示內建，也不會因此被下一次儲存覆蓋。
- **語意校正回覆遺失**：回覆遺失或逾時後，下一個按鍵不再被擋住。這項來自程式檢查與故障注入，尚未證實對應到特定的實際症狀。
- **模型備註快取損壞**：不再影響已下載模型清單的載入，無效的快取當作沒有備註。
- **更新按鈕**：各種狀態都維持主題樣式。

## 更新

- **更新通道**：「關於與相容性」新增正式版／測試版選項。預設正式版，只有選測試版才會列出測試版；正在執行測試版且沒選過時預設測試版。切換通道時會清掉舊通道的選擇，不會下載到另一個通道的版本。
- **測試版版本判斷**：更新檢查能正確比較 `-beta.N`：測試版比前一個正式版新，比自己的正式版舊。

## 與上游不同

單按數字鍵的顯示、數字鍵盤、右鍵翻頁與更新通道都是 Windows 版的行為，詳見 `UPSTREAM-CHANGES.md`。上游版本與內建模型不變。

## 已知問題

- Shift 切換中英文失效（#3）本版沒有修正。

## 個人資料與回報

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。已開啟的應用程式要重新開啟才會用到新版。

自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用。遇到問題請回報：善解版本、Windows 版本、在哪個應用程式發生、按了哪些鍵、預期和實際的結果。
