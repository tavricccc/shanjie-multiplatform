# 善解輸入法 0.15.4-beta.1

Windows 測試版（pre-release），以 0.15.3 為基礎。正式版使用者預設不會收到這版；要試用請到「關於」把更新通道切到測試版，或直接執行安裝檔。

## 新增

- **更新通道**：「關於」可選正式版或測試版。預設正式版；正在執行測試版且沒選過時預設測試版。
- **數字鍵盤輸入數字**：沒有候選可選時，數字鍵盤 0–9 視為純數字；有候選時仍可選字。
- **→ 右鍵換下一頁候選**：新增選項，預設關閉。開啟後 → 翻頁，↓ 仍移到下一個候選字。

## 修正

- **重開設定後模型變回內建**：設定視窗啟動時不再把已選的下載模型改成內建，也不會因此被下一次儲存覆蓋。
- **單按數字鍵顯示注音**：使用「上游判斷」或「兩者並用」時，單按數字鍵會顯示數字，按 Enter 送出數字；仍可繼續組成注音（`184` 是「爸」）。`5 空白` 仍是「之」，畫面是 `1` 時按 ↓ 仍開 ㄅ 的清單。
- **語意校正回覆遺失後擋住按鍵**：未確認的語意校正會先補完，不再擋住下一個按鍵。這項來自程式檢查與故障注入，尚未證實對應到特定的實際症狀。
- **備註快取損壞時模型清單載入失敗**：無效的備註快取當作沒有備註，已下載模型仍會列出。
- **更新按鈕樣式**：每個狀態都維持主題樣式。

## 與上游不同

單按數字鍵的顯示、數字鍵盤行為、右鍵翻頁與更新通道都是 Windows 版的行為，詳見 `UPSTREAM-CHANGES.md`。

## 個人資料與驗收

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。上游與內建模型不變。

Shift 切換中英文失效（#3）本版沒有修正。自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用；安裝後請重新開啟使用輸入法的應用程式再測試。
