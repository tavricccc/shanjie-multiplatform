# 善解輸入法 0.16.1-beta.2

日期：2026-11-27。這次 Windows 測試版同步原作者善解 v0.9.1 與其後主線（`de7d69c5`）的詞庫讀音與輸入改進，並整合疊加詞庫裁剪、8,441 詞台灣專名詞庫、部分符號使用半形、麥注音標點排列、單按 Shift 保留組字、半形英數自動空格、原鍵混打正式拼寫與語意校正排程最佳化。

本版已通過 GitHub CI，各變更亦附本機驗證結果，尚未收到實際安裝後的日常使用回報。希望維持正式版本的使用者，可繼續使用 [0.16.0](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.16.0)。

## 新增功能

- **詞庫與台灣專名擴充**：同步原作者 `de7d69c5` 補上「為啥」、「不足為外人道」、「部署」等讀音，恢復「系上」、「挨到」，並整合上游疊加詞庫裁剪（移除 533 個罕用詞之 549 筆讀音）與 8,441 詞台灣專名層（含「浮洲站」、「善解輸入法」、「小檜溪」等及 47 個政府開放資料集授權標示）。
- **部分符號使用半形**：中文模式下可自訂 27 個符號鍵改以半形輸入，開關預設關閉，啟用時套用上游預設的 14 鍵配置，並支援全／半形候選回選與操作預設匯入／匯出。
- **麥注音標點排列**：標點頁新增「善解／Apple」與「麥注音」排列切換（預設維持善解／Apple）；選用麥注音時 `Shift+2`–`8` 輸出 `＠＃＄％︿＆＊`，`Shift+'`、`'`、`\` 分別改為 `；`、`、`、`＼`（倚天單按 `'`、`=` 維持注音鍵）。
- **單按 Shift 切英數保留組字**：標準注音關閉中英混打時，單按 Shift 切到英數會丟棄未完成音節並保留已完成組字，可直接接打英數並切回中文續打後一次送出；倚天切到英數時先送出已完成部分。
- **原鍵混打套用英文正式拼寫**：新增獨立開關 `[input] mixed_english_writing`（預設開啟），於原鍵混打下套用上游正式拼寫表（如 ChatGPT、GitHub、macOS），保留重複鍵容錯與刻意輸入的大小寫；關閉後恢復逐字原樣。
- **半形英數自動空格**：啟用「中英文之間自動加空格」時，半形英數模式於漢字後輸入首個 ASCII 字母或數字亦自動補半形空格（支援 Caps Lock，私密欄位、修飾鍵組合與終端機／程式編輯器保留直通）。

## 效能與修正

- **上游英文模式 Shift 正式大小寫**：修正上游判斷模式下以 Shift 起頭的英文單字（如 `Chatgpt`、`Github`、`Macos`）未套用正式拼寫表的問題，並避免 `GPT`、`CPU` 等縮寫被誤切為注音。
- **語意校正排程最佳化**：將每個工作階段專用的 `Shanjie rerank` 背景執行緒優先序由 `BELOW_NORMAL` 調整為 `THREAD_PRIORITY_NORMAL`（程序與其他執行緒優先序、Enter 100 ms 等待預算不變），高負載下兩秒內校正套用率大幅提升。

## 與上游不同之處

- 原鍵混打為 Windows 專屬模式，其獨立正式拼寫開關 `[input] mixed_english_writing` 在兩套操作範本與缺省設定皆預設開啟。
- 語意校正僅調整各工作階段專用 `Shanjie rerank` 執行緒為 `THREAD_PRIORITY_NORMAL`，維持既有 Named Pipe／TSF 架構。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不含任何私人詞典。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

本次為 Windows 測試版，支援 x64 Windows 與 32 位元應用程式。
