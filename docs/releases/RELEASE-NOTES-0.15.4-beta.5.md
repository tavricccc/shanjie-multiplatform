# 善解輸入法 0.15.4-beta.5

Windows 測試版（pre-release），延續 0.15.4-beta.4。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 修正與改善

- **核心記憶體減少**：載入整組內建模型後，核心 Private 從約 202 MiB 降到約 161 MiB。
- **載入更快**：載入整組內建模型從約 1.5 秒降到約 1.25 秒。
- **再開一個會話更快**：同一詞庫與模型再開會話從約 0.3 秒降到約 1 毫秒，每個會話多占的 Private 從 5.6 MiB 降到 2.7 MiB。
- **開會話不再互相等待**：一個會話載入資源時，其他應用程式開啟或恢復會話不必等它。
- **發布建置最佳化**：`Shanjie.dll` x64 從 4.78 MB 降到 4.54 MB，x86 從 4.02 MB 降到 3.83 MB。

候選與排序結果不變：改動前後各跑 3 輪（每輪 7680 鍵、1860 次語意校正），輸出相同。以上數字來自隔離環境，真實應用程式中的體感尚未實測。

## 與上游不同

核心記憶體的改動是 Windows 版對上游程式的覆蓋，不改變結果，詳見 `UPSTREAM-CHANGES.md`。上游版本與內建模型不變。

## 個人資料與回報

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。已開啟的應用程式要重新開啟才會用到新版。

自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用。遇到問題請回報：善解版本、Windows 版本、在哪個應用程式發生、按了哪些鍵、預期和實際的結果。
