# 善解輸入法 0.15.4-beta.4

Windows 測試版（pre-release），延續 0.15.4-beta.3。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 新增

- **自動檢查更新**：登入時與之後每天向 GitHub 查一次，有新版時在螢幕右下角顯示通知卡片，一天最多一次；開啟設定程式時只要有新版也會通知。全螢幕或勿擾時排程檢查不打擾。按「查看更新」開啟「關於」頁，由你決定是否下載，不會自動下載。查詢不傳送輸入內容，可在「關於」關閉「自動檢查更新」。

## 修正與改善

- **玻璃視窗可讀性**：設定、安裝程式與更新卡片在深色或鮮豔的背景上，文字不再難以辨識；次要文字也加深。

## 行為變更

- **自動檢查更新預設開啟**：安裝時會新增排程 `ShanjieUpdateCheck`，解除安裝時移除。
- **玻璃看起來比較不透明**：任何背景最多透出 20%，「玻璃濃度」改為從這個下限調到不透明，既有數值看起來會比以前濃。

## 與上游不同

以上行為都是 Windows 版獨有，詳見 `UPSTREAM-CHANGES.md`。上游版本與內建模型不變。

## 個人資料與回報

更新使用 `Shanjie-Windows-Setup.exe`。既有設定、個人詞典、學習與下載的模型沿用；不含私人詞典。已開啟的應用程式要重新開啟才會用到新版。

自動測試使用隔離核心與 TSF context，不能取代真實應用程式的日常使用。遇到問題請回報：善解版本、Windows 版本、在哪個應用程式發生、按了哪些鍵、預期和實際的結果。
