# 善解 Windows 0.10.0 測試版

日期：2026-10-17。本版新增線上模型管理、雙 Ctrl 快捷加詞與混打重複鍵容錯，修復唯一設定視窗、Shift 組合鍵與設定更新恢復等問題。上游核心固定於 main `b2f5da8`（v0.4.6），本次不自動安裝或發布遠端；實際驗證結果與尚待驗收的宿主見 [VERIFICATION.md](https://github.com/tavricccc/shanjie-windows/blob/68796049b3f19a67217c15c559ea8be2819ad3e2/VERIFICATION.md)。

## 線上模型管理

安裝包只內建 **model-v6＋classes-v5**。設定 → 一般 → 模型配置旁的「取得其他模型」讀取善解上游 GitHub Releases，結合 Windows 相容配套表，顯示內建、已下載、可下載及尚未確認相容的版本。

選擇配套後按「下載並選取」：顯示進度、支援取消及再次下載時續傳，核對附件大小、SHA-256、主模型／詞類表配對，再於背景轉換並驗證 Windows 映射格式。全部完成後才列入可選清單；下載不會保存其他草稿，按主視窗「儲存」後才套用。有組字時先提交目前組字，再切換模型。

目前相容表提供 model-v6＋classes-v5、model-v6＋classes-v4，以及 model-v5＋classes-v3。相同主模型共用下載快取；下載配套不表示新版本必然在所有輸入情境更準確。早期開發核心（f8ea0bb）、公開 dev302／無 KN 配置曾測得 v4 242/302、v5 238/302，這是歷史測量，不冒稱本版已重新取得相同分數。

模型保存在 `%LOCALAPPDATA%\Shanjie\Models`，可用旁邊的「開啟模型資料夾」與「重新掃描」管理。只有通過校驗的完整 Windows 配套會列入主選單；任意丟入原始附件不會自動成為可用模型。尚未確認相容的新發布版本不能下載套用，KN／trigram／tiny-LM 附件不會當成可選主模型。

離線時內建與已下載模型仍可用，線上清單顯示最後成功取得的快取及時間。下載中斷、取消、檔案不符都不會切換模型。已選配套遺失或無效時，新核心使用內建配套備援並保留原選擇；原有組字與個人資料不因此清除。升級前明確選用舊內建 classes-v4 者，安裝工具會先將已有配套保存在使用者模型資料夾。程式更新不會清除這個資料夾。

## 混打、大小寫與設定

- 混打方式集中為「關閉／Windows 注音順序／上游英文詞表／兩者並用」。全新安裝預設關閉；升級保留原設定。
- 上游英文詞表模式本版限標準注音。倚天保留原有 Windows 混打與容錯，相關上游英文選項反灰；跟隨已安裝配置時，以實際鍵盤判定是否啟用。
- 上游英文模式的 Shift＋字母開始英文組字段；後續 Shift 字母繼續接在同一段。Windows 實際字元狀態獨立於注音鍵傳遞，處理 Caps Lock 及 Shift＋Caps Lock，保留單按 Shift 切換的既有設定。
- 英文詞表建置輸出固定為 LF，並檢查字元、字長及重複項，避免 Windows CRLF 讓上游嚴格讀取器拒絕整份詞表。
- 相鄰重複鍵容錯預設關閉，只處理 Windows 注音判斷負責的片段；已進入上游英文段的字母不自動改寫。原始按鍵候選保留。
- 設定採分頁方式，新增唯一設定視窗與啟動轉送，保留未儲存草稿，加入雙 Ctrl 加詞與快捷鍵設定；已開啟的舊 0.9.x 設定窗優先恢復，以保留草稿。

## 混打重複鍵容錯

設定 →「組字與提交」→「混打相鄰重複鍵容錯」。預設關閉，須同時開啟中英混打，適用標準／倚天注音。

第一版處理短音節中多按一次相同鍵的情況。例如標準鍵盤輸入「回家」多按一次開頭的 c，在有聲調及詞庫讀音支持時可預選「回家」。原始按鍵仍在候選內，選回後不會再次自動改寫同一個字面片段。只處理尚未提交的組字，不刪除 App 裡已經提交的文字。

這是有限的重複鍵容錯。不同按鍵的誤按、任意漏字、縮寫與中文混用並不會全部自動修正；仍可能存在刻意英文與注音的歧義，可隨時關閉。

## 反白字詞後快捷加詞

在使用善解的可編輯欄位反白 **1–32 個已提交漢字**，純按下並放開 Ctrl 兩次，詞旁會顯示附屬浮層。確認讀音後，按「加入」或 Enter 保存；Esc／「取消」關閉。第一次顯示不搶焦點，也不修改原文字與反白範圍。

浮層會提供內建詞庫的讀音建議，多音字仍須自己確認。直接輸入標準／倚天注音按鍵可重填整段建議，Ctrl+A 清空，空白分節，聲調後接下一字會自動分節，Backspace 修改。未知詞可逐字填寫讀音，字數與音節數必須相符。失敗時保留浮層內容供修正或重試。

設定 →「切換與快捷鍵」可關閉功能、指定左右 Ctrl、調整 200–1000 毫秒間隔，或改用 **Ctrl+Shift+F12**。PowerToys「尋找我的滑鼠」也可使用雙 Ctrl；遇到衝突時請改用替代快捷鍵。

第一版需要 App 提供 TSF 可讀取的選取文字與位置；唯讀網頁文章、PDF、自繪畫面及不提供文字範圍的程式不保證支援。密碼／停用輸入法／唯讀欄位不提供此功能，不會自動複製或讀取剪貼簿。實際記事本、Office、瀏覽器及 AppContainer 相容性以驗證紀錄所列範圍為準。

## Enter 只提交游標前的文字

開關位於「組字與提交」。游標在已完成組字的中間時，Enter 提交前段，後段繼續組字；固定多字詞不會被切開，切點必要時移到整詞末端。候選中 Enter 仍先確認候選，再依提交設定處理。

全新 Windows 操作預設開、善解操作預設關。舊設定若沒有此欄位，遷移後保持原有的整句提交；已有明確設定者保留原值。載入操作預設則按所選預設調整。

## 設定視窗、Shift 與個人詞庫修正

- 同一使用者、登入工作階段與設定資料範圍只開啟一份設定視窗；再次啟動會恢復既有視窗，保留未儲存草稿。舊 DLL 會透過目前註冊版本開啟設定，已存在的舊版設定窗優先恢復。
- Shift 組合鍵於 TSF 試探／正式按下及放開前觀察；執行緒範圍 hook 補足宿主沒有送入 TSF 的鍵盤訊息，照常放行、不記輸入文字，保留單按 Shift 切換。
- 個人詞庫新增與設定保存共用鎖定及合併流程，處理兩程序同時新增、重複新增與較舊設定草稿，避免新詞被覆寫。
- 核心驗證對 Windows 保留未完成讀音及標點的政策使用明確預期，更新學習及模型配套 fixture；不修改上游追蹤檔，也不跳過整組失敗測試。

## 核心與資料保護

修復設定操作逾時或中斷後停止刷新候選的缺口：逐一確認操作，從未確認的操作續接，後續按鍵依序等待；不重送已確認操作。自動等待達期限後保留狀態並提示重試，Esc 取消，失焦不將舊操作套用到其他欄位；英文設定也走同一條恢復流程。常駐核心只繼承 NUL 標準控制代碼，並以自身程式目錄啟動，避免保留呼叫端的輸出管線及鎖住原工作目錄。

個人詞庫、學習資料及未儲存詞庫草稿與模型分開；操作預設保留使用者模型選擇，匯出的操作預設不攜帶模型選擇或私人詞庫。本機 TODO、私人詞庫與學習檔不納入安裝包。

## 驗證與限制

完整核心 418 項、Windows crate 兩架構各 33 項，以及輸入、恢復、模型管理與 WinUI 隔離回歸的詳細結果見 [VERIFICATION.md](https://github.com/tavricccc/shanjie-windows/blob/68796049b3f19a67217c15c559ea8be2819ad3e2/VERIFICATION.md)。舊 x86 check 286 的確切間歇觸發條件仍待觀察，不能以目前回歸通過宣稱已確認歷史根因。前景 App 長時間輸入、雙 Ctrl 浮層位置／DPI、真實 UAC／升級與登入預載尚待驗收，不以隔離通過代替實機結果。
