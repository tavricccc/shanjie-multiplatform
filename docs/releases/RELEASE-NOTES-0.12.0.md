# 善解 0.12.0 測試版（Windows／Linux）

日期：2026-10-20。上游維持善解 v0.4.7 Release，核心、詞庫與內建模型未變。

## 新增

- **WinUI 3 安裝畫面**：安裝包根目錄的「安裝善解.exe」會顯示這次是全新安裝、升級或同版修復，選擇標準注音或倚天（升級時預選目前配置）後逐步顯示安裝進度；失敗時列出停在哪個階段、回復結果與紀錄位置，完成後可直接開啟設定。
- **WinUI 3 解除安裝畫面**：從「已安裝的應用程式」或設定「關於與相容性」頁的「解除安裝善解…」開啟，可選擇保留或一併移除個人詞庫與學習。畫面先複製到暫存資料夾執行，讓安裝目錄能完整移除，結束後清掉這份暫存。
- **CI 安裝包**：GitHub Actions 建置 Windows zip 與 Linux tar.gz（Fedora 44 容器），附到對應版本的 Release。

## 優化

- **更早啟動常駐核心**：改由工作排程器的登入工作 `ShanjieCore` 啟動，不再等 Explorer 延後處理的 `Run` 啟動項目。升級時移除舊的 `Run` 值，解除安裝時一併移除排程。

## 相容性

- `install.cmd`、`uninstall.cmd`、`重新選擇鍵盤.cmd` 與 `shanjie-manager` 命令列照常可用；manager 新增 `install-status` 與 `--progress`。
- 「已安裝的應用程式」的解除安裝改開 WinUI 畫面。
- 設定 schema 不變，個人詞庫、學習與已下載的模型沿用。Linux 版只有版本號與 CI 建置變更。

已通過 Rust 單元測試、設定與安裝畫面的離屏 render（淺色／深色）、背景 TSF harness 與打包校驗，並已在實機完成安裝、升級與解除安裝。
