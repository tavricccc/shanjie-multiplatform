# 善解 Windows 0.5.2

日期：2026-10-13。本版集中修正輸入提交、核心復原、個人詞典保存與安裝流程。沿用固定上游 `368eebc426981852094d8c0c49b8b0618143bd2b`、model-v5／classes-v3 與內建詞庫；私人詞典不包含在程式、模型或發佈包內。

## 輸入與常駐核心

- 修正傳統 cmd 中英混打 `adb` 變成 `aadb` 的原因：先建立自己的 TSF 組字，再寫首字；提交與剩餘組字分開處理。回歸同時核對組字結束通知與文字，不只看最後畫面。
- 延後回呼同時檢查欄位與組字世代。離開後回到同一欄位，舊回呼也不能修改新組字；原欄位已捕獲的組字仍完成一次提交。
- 常駐核心的讀寫改為可取消、有期限的等待。一般請求 750 ms、重連 1.5 秒，首次啟動上限 30 秒；學習鎖單次等待 250 ms。忙碌、斷線、逾時與結果未知分開處理。
- 忙碌時按鍵與選字操作按順序保留在記憶體，受原欄位與世代限制，最多自動重試 5 秒。超過期限顯示保留提示，下一鍵可再試，Esc 可明確取消。學習鎖忙碌不再誤走原文轉英數備援提交。
- 核心使用會話與請求序號確認已處理的結果，避免丟失回覆後重複提交。核心重啟只重建已確認的未提交組字；已處理與否無法確認時保留並提示，不盲目重播學習或提交。
- 保持 64 個管線實例上限；新增會話超出容量會在有限時間失敗，已有會話繼續工作。接聽端重新建立採退避，釋放連線後可再接受。

## 安裝與設定

第一次安裝或由沒有配置紀錄的舊版升級，會先盤點註冊與清單，再詢問標準注音或倚天；只註冊選定配置，x64／x86 一致。已有單一配置紀錄的升級沿用選擇。取消選擇不開始變更。

要更換配置，執行解壓目錄的 `重新選擇鍵盤.cmd`。命令列也可用 `tools/shanjie-manager.exe --elevate install --keyboard standard` 或 `--keyboard eten`。安裝配置保存在 `installed.json`，與 `profile.ini` 日常偏好分開；設定中未安裝鍵盤反灰，舊偏好退回跟隨已安裝配置並顯示說明。共用設定與拼音仍可使用。

安裝前保存 COM、TSF profiles／categories、兩架構、使用者清單與順序、啟動路徑、Installed Apps 與 Run 資訊。部分註冊失敗也會進入回復；全部校驗成功後才退役舊版本。回復未完成時報告失敗項目、保留版本與 `.installer-recovery` 紀錄，避免移走仍被引用的 DLL。原生 Windows 註冊及回復尚待另外授權的實機驗收。

## 個人詞庫與學習

- 內容雜湊詞典重用前核對完整內容；獨立暫存檔完整寫入並同步後才發布。同內容的跨程序保存共用鎖，避免把未寫完的檔案當成成功。
- 截斷或錯誤檔案先移到同目錄 `.deleted_files` 再修復。保留 0.5.1 的 LF、CRLF、CR／混合換行及既有格式驗證。
- 清除學習正確捕捉原生 `InvalidDataException`。逾時或部分清除失敗顯示錯誤，保留未儲存草稿與設定；重試成功後更新 epoch。確認對話框與清除範圍不變，檔案可從 `.deleted_files` 找回。
