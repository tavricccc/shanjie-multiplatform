# 善解 Windows 0.9.0

日期：2026-10-16。同步上游 main b2f5da8（v0.4.6）並使用 classes-v5；新增中英混打的獨立開關與「Enter 只提交游標前的字」。

## 上游同步

- 上游核心固定在 main b2f5da8（v0.4.6），詞類表改用 classes-v5，模型仍為 model-v6。
- 上游新增的 trigram 核心已一併編入，但正式 trigram 資料尚未發佈，Windows 版目前不啟用。

## 中英混打

- 三個彼此獨立的開關：注音順序（Windows 版混打）、英文詞表（上游的詞表判定與行內英文）、兩者並用，另有「顯示已輸入的字母」開關。
- 設定窗重新分組，選字、輸入、標點各自一頁。

## Enter 只提交游標前的字

- 游標在組字中間時，Enter 只送出游標前（選字後含所選的字）的部分，後面的字留在組字區可繼續選字；固定詞不會被切開。
- 設定在「選字」頁：「Enter 只提交游標前的字」，Windows 互動預設開，善解互動預設關；關閉時一律整句送出。

## 修復

- 常駐核心啟動時不再繼承呼叫端的工作目錄；先前從封裝資料夾執行安裝程式時，核心會一直鎖住該資料夾。

## 驗證

- 核心單元測試涵蓋游標前提交與關閉時整句提交，並逐一檢查每個輸入選項位元都被接受。
- WinUI 離屏驗證與封裝驗證（628 個檔案）通過。
- 已知既有失敗：`row2_punctuation`、`engine_predict`（2）、`engine_english` 一項標點測試。

## 未驗證

- 真實 TSF 應用程式內的 Enter 流程（候選中第二個 Enter）、Shift／Caps Lock 與上游英文並用的手感、x86 TSF 實機輸入。
