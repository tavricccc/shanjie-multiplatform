# 善解 Windows 0.9.0

**本次交付為測試包，尚未安裝或完成全部驗收。** x86 常駐核心 TSF smoke 的「開啟預測後顯示候選」校驗（check 286）仍失敗，直接核心路徑通過，原因尚未定位；不將它宣稱為已修復或所有 App 已驗收。相關證據與後續入口見 VERIFICATION.md 及本機 TODO。

設定視窗重複開啟、Shift 組合鍵判斷及標點測試契約修正，並加入混打容錯與選取詞條快捷新增。安裝方式沿用既有安裝包；本次製作版本不會自動安裝到目前系統。

## 混打重複鍵容錯

設定 →「組字與提交」→「混打相鄰重複鍵容錯」。預設關閉，須同時開啟中英混打，適用標準／倚天注音。

第一版處理短音節中多按一次相同鍵的情況。例如標準鍵盤輸入「回家」多按一次開頭的 c，在有聲調及詞庫讀音支持時可預選「回家」。原始按鍵仍在候選內，選回後不會再次自動改寫同一個字面片段。只處理尚未提交的組字，不刪除 App 裡已經提交的文字。

這是有限的重複鍵容錯。不同按鍵的誤按、任意漏字、縮寫與中文混用並不會全部自動修正；仍可能存在刻意英文與注音的歧義，可隨時關閉。

## 反白字詞後快捷加詞

在使用善解的可編輯欄位反白 **1–32 個已提交漢字**，純按下並放開 Ctrl 兩次，詞旁會顯示附屬浮層。確認讀音後，按「加入」或 Enter 保存；Esc／「取消」關閉。第一次顯示不搶焦點，也不修改原文字與反白範圍。

浮層會提供內建詞庫的讀音建議，多音字仍須自己確認。直接輸入標準／倚天注音按鍵可重填整段建議，Ctrl+A 清空，空白分節，聲調後接下一字會自動分節，Backspace 修改。未知詞可逐字填寫讀音，字數與音節數必須相符。失敗時保留浮層內容供修正或重試。

設定 →「切換與快捷鍵」可關閉功能、指定左右 Ctrl、調整 200–1000 毫秒間隔，或改用 **Ctrl+Shift+F12**。PowerToys「尋找我的滑鼠」也可使用雙 Ctrl；遇到衝突時請改用替代快捷鍵。

第一版需要 App 提供 TSF 可讀取的選取文字與位置；唯讀網頁文章、PDF、自繪畫面及不提供文字範圍的程式不保證支援。密碼／停用輸入法／唯讀欄位不提供此功能，不會自動複製或讀取剪貼簿。實際記事本、Office、瀏覽器及 AppContainer 相容性以驗證紀錄所列範圍為準。

## 其他修正與資料更新

- 設定程式使用同使用者、登入工作階段及資料範圍的唯一視窗。再次開啟會回到原視窗，保留未儲存草稿；已安裝舊版設定視窗尚存時優先恢復它。舊 DLL 會透過目前註冊版本開啟設定。
- Shift 組合鍵於 TSF 試探／正式按下及放開前觀察；執行緒範圍 hook 補足宿主沒有送入 TSF 的按鍵訊息，照常放行，不記輸入文字。單按 Shift 切換仍保留。
- 個人詞庫新增與設定保存共用鎖定及合併流程，處理兩程序同時新增、重複新增及較舊的設定草稿，避免新詞被覆寫。
- 設定 →「一般」→「模型配置」可選 **model-v6＋classes-v5**（新配套，預設，μ 0.2）或 **model-v6＋classes-v4**（舊配套，μ 0.8）。儲存後核心載入所選配套，已有組字會先提交；個人詞庫與學習資料沿用。兩項共用 model-v6 主模型，差別是詞類表權重；沒有新增 KN／語意模型功能，也沒有把私人字典放入安裝包或內建資料。

**已知資料取捨：** 在目前 Windows 不啟用 KN 的對應參考配置、上游公開 dev302 測試集上，classes-v4 首選正確 242/302，classes-v5 為 238/302，候選前 64 名涵蓋率均為 300/302。經使用者確認，此版仍採用 classes-v5 並公開記錄這項退步。這是單一公開測試集的結果，不代表所有輸入情境，也不能沿用上游完整 KN／語意重排配置的改善幅度。
