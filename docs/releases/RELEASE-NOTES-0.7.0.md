# 善解 Windows 0.7.0

日期：2026-10-15。本版改善中英混打的數字、標點與亂序注音，新增空白鍵輸入注音符號的開關及注音候選。沿用 0.6.1 的設定共存修正與提權等待期限；上游 pin、內建詞庫、模型和解碼評分不變。

## 數字與標點留在組字中

沒有組字、且關閉單獨聲調符號時，`3`、`4` 等聲調鍵會由輸入法插入原本的數字；反斜線等字面標點也使用相同的可靠處理方式，避免依賴應用程式補回未處理的按鍵。

輸入 `()`、反斜線或已啟用的中文標點時，不再先提交英文／中文組字。未完成讀音後的標點會暫留在該讀音後方，完成聲調後仍跟在轉換結果後；Backspace 可先刪掉這些標點。原有聲調、候選數字選字、Ctrl 標點、逐鍵中文標點與全半形規則仍生效。

## 混打的英文字母亂序注音

按下明確聲調鍵後，優先檢查整段按鍵是否可重排成有效注音，且詞庫有候選；不成立才嘗試英文前綴與注音尾段。例如標準鍵盤 `ji3`／`ij3` 都可轉成「我」，`d04`／`0d4` 仍可轉成「看」，`callsu3` 仍可得到「call你」。一般字母輸入與空白鍵的英文判斷繼續沿用保護規則。

英文字母加數字有歧義，例如 `us4` 也能解釋為「逆」。混打轉換的文字候選會保留原始按鍵，排在第一個國字候選之後，可用對應的數字或滑鼠選回。這不是保證自動辨識所有英文意圖；原始字串提供另一個明確選擇。

## 空白鍵輸入注音符號開關

設定位置：「組字與提交」→「空白鍵」→「空白鍵輸入注音符號」。相容預設為開啟，既有設定缺少這個欄位時也視為開啟；操作預設匯入／匯出會保存此選項。

- **開啟：** 沿用原有注音符號輸入，例如標準鍵盤 `1＋空白` 顯示「ㄅ」，仍在組字中，Enter 才提交。
- **關閉：** 空白仍完成有效第一聲，例如 `ji＋空白 → 窩`。若沒有可轉換的國字，便還原原始按鍵與一個空格，例如 `1＋空白 → 1 `，不輸出「ㄅ」。是否提交依原有「空白鍵提交組字」設定處理，不會再多補一次空格。
- **關閉時的注音候選：** 完成國字後開啟文字候選，第一項提供目標字／詞的實際讀音，例如「我」對應「ㄨㄛˇ」、「你好」對應「ㄋㄧˇㄏㄠˇ」。預設反白仍在國字；數字 `1` 或滑鼠可選取注音，只替換目標範圍，繼續留在組字中。候選 Enter 遵循原有整句提交設定。

注音讀音取自實際輸入音節，保留聲調及多音字的輸入讀音，不從國字重新猜音。注音候選不參與國字選字學習，也不受 Big5 國字篩選移除；系統明確區分字面注音與尚未完成的讀音。英文、標點、未完成讀音提示、預測及聯想列不因此添加注音候選。
