# 善解輸入法 0.16.0-beta.3

日期：2026-11-18。這次 Windows 測試版同步原作者善解 v0.8.0 的核心與完整詞庫，並修正 PowerPoint 無法輸入中文的問題。

本版通過 GitHub 上的輕量 CI，各 PR 也附了開發者本機的測試結果，還沒有收到安裝後的日常使用回報。希望維持正式版本的使用者，可繼續使用 [0.15.3](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.15.3)。

## 新增功能

- **同步善解 v0.8.0**：採用原作者 v0.8.0 的逐鍵讀音解碼、多音字詞頻、句首單字學習與異體字排序，選字更準。
- **新詞包**：新增美妝與保養（539 詞）、迷因與直播（139 詞）兩組詞包，與上游一樣預設開啟。ACG、IT 照舊開啟，經典台詞照舊關閉。
- **中英混合詞**：可直接打出 ChatGPT、CP值、SIM卡等詞，英文採正式拼寫。
- **參考游標前文**：開始組字時參考同一行游標前最多 64 個字，讓候選更貼近上下文。沿用「使用游標前文」開關，不儲存這段文字。
- **快打更不容易打錯**：數字鍵順序顛倒，或聲調太早按下時，能還原成正確讀音。

## 穩定性修正

- 修正 PowerPoint 投影片文字方塊被誤判為唯讀，無法組字、右 Shift 也無法切換中英的問題。

## 與上游不同之處

- Windows 保留覆打判英文與單按 Shift 切換，兩個範本仍預設開啟，既有設定不重設；上游 v0.7.0 在 macOS 預設關閉。
- 模型清單與附件優先從原作者倉庫讀取，讀取失敗才改用鏡像。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不含任何私人詞典。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

本次為 Windows 測試版，支援 x64 Windows 與 32 位元應用程式。PowerPoint 反白文字的加詞擷取仍在調查。
