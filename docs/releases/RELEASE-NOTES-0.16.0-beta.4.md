# 善解輸入法 0.16.0-beta.4

日期：2026-11-18。這次 Windows 測試版改善 Shift 英文接中文、TSF 相容性與詞包切換，並補齊箭頭等符號候選。

本版通過 GitHub 上的輕量 CI，PR 也附了開發者本機的測試結果，還沒有收到安裝後的日常使用回報。希望維持正式版本的使用者，可繼續使用 [0.15.3](https://github.com/tavricccc/shanjie-multiplatform/releases/tag/v0.15.3)。

## 新增功能

- **詞包切換不打斷輸入**：切換詞包時在背景建立新的詞庫，期間可以繼續打字，等目前的組字結束再換上；個人詞典與學習資料照常保留。
- **更多符號候選**：減號可選 `→`、`←`、`…`、`⋯`，正斜線可選 `↗`、`↙`，反斜線可選 `↖`、`↘`，星號可選 `※`，全半形都適用。
- **長句標示目前詞段**：組字時依游標與候選範圍標出正在選的詞段。

## 使用上的改善

- **Shift 英文接中文更順**：放開 Shift 後，可直接接單一符號、第一聲或正序／倒序注音；Shift＋空白會保留英文段裡的空白。
- **聲調太早按也能還原**：原鍵混打與數字層都能還原提早按下的聲調，一般數字與英文不受影響。
- **Enter 送出更準**：直接提交時最多等 100 毫秒，讓語意校正來得及套用，逾時照樣送出。

## 穩定性修正

- 改善部分程式拒絕同步編輯時的處理，Tab 與焦點切換時不再重複處理按鍵；前文讀取與無視窗候選定位失敗時會自動降級。

## 預設值變更

- **英文覆寫改為預設關閉**，與上游一致。之前沒有儲存這個設定的使用者，更新後會變成關閉；明確儲存過的值會保留。

## 更新與資料

執行 `Shanjie-Windows-Setup.exe` 更新。一般更新會沿用個人詞典、學習資料、設定與已下載模型；本版不含任何私人詞典。更新後請先儲存工作，再登出並重新登入或重新開機，讓原本已開啟的程式使用新版。

本次為 Windows 測試版，支援 x64 Windows 與 32 位元應用程式。PowerPoint 實際操作與反白加詞仍待驗收。
