# 善解輸入法 0.15.4-beta.3

Windows 測試版（pre-release），延續 0.15.4-beta.2。正式版使用者預設不會收到這版；要試用請到「關於與相容性」把更新通道切到測試版，或直接執行安裝檔。

## 新增

- **→ 右方向鍵選單**：原本的「→ 右鍵換下一頁候選」開關改成「無／下一頁／展開」三選一，預設「無」。舊設定會自動對應（關→無、開→下一頁）。「展開」以三欄多列顯示候選，↑／↓ 逐項移動，頂列 ↑ 收回；放不下時只顯示裝得下的列數，並隨選取捲動。

## 修正與改善

- **九宮格字面輸入**：九宮格的數字與 `+ - * / .` 不再當注音，一律進組字區，可繼續編輯或按 Esc 取消；候選開啟時 1–9 仍選字。有未完成讀音時先送出讀音；`` `u ``、`` `b `` 內碼輸入中可用九宮格打數字。
- **全／半形**：Shift＋空白切換時立即更新組字區，失焦送出也採相同寬度；切回半形可還原。
- **反引號標點**：補上 Shift 數字列符號、減號／底線與波浪號；內碼輸入不再被拼音攔截，進入時也不會遺失拼音組字。安裝更新後會通知已開啟的視窗重新載入設定。
- **模式圖示**：系統匣 16–24 px 與游標旁提示的「中／A」放大，較容易辨識。

## 行為變更

- **反引號標點預設開啟（Windows 範本）**：舊版 Windows 設定升級時會一次改為開啟，**包含先前手動關閉的設定**，因為舊設定檔分不出是預設還是手動關閉；要關閉請到設定重新關一次，之後會保留。善解範本維持關閉。
- **閒置時按九宮格不再直接交給應用程式**：數字會先進組字區，需要 Enter 送出。在 Excel 等軟體裡，打完數字要多按一次 Enter；中文模式下，以九宮格當快捷鍵的軟體也收不到這些按鍵。
- **全形模式下九宮格輸出全形字元**：先前（beta.1）是半形。

## 與上游不同

以上行為都是 Windows 版獨有，詳見 `UPSTREAM-CHANGES.md`。上游版本與內建模型不變。
