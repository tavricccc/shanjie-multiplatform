# 善解輸入法 0.12.2

日期：2026-10-24。這次 Windows 更新改善中英切換、雙 Ctrl 加詞及加詞視窗的操作穩定性。支援 x64 Windows 與 32 位元應用程式；Linux 版維持 0.12.1。

## 使用上的改善

- **Shift 切換更可靠**：改善部分程式中單按 Shift 無法切換中英的情況，保留 Shift+Enter、Shift+字母等組合鍵原本的操作。
- **改善開始輸入時的掉字問題**：短暫切換編輯焦點時保留正在輸入的內容，減少像是 Excel 儲存格開始編輯時遺失第一個字的情況；真正切換欄位或程式時仍會正常結束組字。
- **雙 Ctrl 加詞更容易觸發**：調整連按節奏的判定，避免稍長按或重複按鍵通知讓操作失效；左右 Ctrl 的選擇及替代快捷鍵維持不變。
- **改善反白字詞的取得**：在更多可編輯欄位嘗試讀取反白字詞。無法取得時會顯示簡短提示，不搶走輸入焦點、不讀取剪貼簿；密碼與唯讀欄位不啟用加詞。
- **加詞視窗開關更穩定**：修正按「取消」、連點按鈕或快速重開時的關閉與焦點處理問題。「加入／取消」不會帶走原輸入欄位的焦點，較早一次操作的結果也不會干擾新開啟的視窗。

## 更新與資料

個人詞庫、學習資料、設定與模型選擇均沿用；內建模型維持 model-v6＋classes-v5。一般發行包不包含輸入診斷控制台，也不會自動收集輸入內容。

執行 `Shanjie-Windows-Setup.exe`，或解開 ZIP 後執行「安裝善解.exe」。更新完成後請先儲存工作，再**登出並重新登入，或重新開機**，讓原本仍載入舊版的程式使用新版；只關閉 Win+R 視窗不一定足夠。

## 已知限制

- **Excel 的反白加詞仍可能無法取得文字**，本版不宣稱已解決所有 Excel 相容性問題。
- Shift 與一般程式的加詞浮層已有使用者回報正常；關閉加詞視窗的修正已通過隔離測試，Win+R 實際滑鼠取消仍待更新後確認。其他程式、螢幕縮放與長時間使用情境也可能有差異。
