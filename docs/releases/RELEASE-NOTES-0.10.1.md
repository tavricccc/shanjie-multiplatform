# 善解 Windows 0.10.1 測試版

日期：2026-10-17。以 0.10.0 為基礎，修復混打數字遺失，改善雙 Ctrl 加詞浮層。

## 混打數字

「Windows 注音順序」或「兩者並用」模式下，原先輸入 `1` 後按 `3／4／6／7`，會因為不完整注音無法配上聲調而漏掉新按鍵。現在依序得到 `13／14／16／17`；連續數字也會保留。有效完整注音照常轉換，例如 `su3 → 你`；數字後接注音可輸入 `13su3 → 13你`。

## 加詞浮層

浮層、文字區及按鈕使用同一套主題。在設定「外觀 → 介面與選字框主題」選「跟隨 Windows」，即可跟隨系統深淺色；也可明確選淺色或深色。系統高對比色優先。

反白漢字並雙按 Ctrl 後，先顯示三種唯讀比對結果：

- 內建詞庫：是否有此詞、是否同讀音。
- 個人詞庫：是否已有此詞、是否同讀音。
- 目前模型：是否包含完整的詞彙項目，並顯示實際模型識別；模型失效時標明內建備援。

語言模型有此詞不代表它提供注音讀法；沒有完整詞條也不代表模型無法組合出這句文字。兩種判定分別顯示，避免混淆。

修改讀音後會重新比對。已有收錄時顯示「仍要加入」，讓你明確確認後指定自己的讀音或優先詞條。若比對尚未完成就按 Enter，會先等待；發現已有詞條時保留草稿，再次確認才加入。比對失敗時保留草稿並允許重試。
