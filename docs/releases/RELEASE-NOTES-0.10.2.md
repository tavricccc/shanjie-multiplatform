# 善解 Windows 0.10.2 測試版

日期：2026-10-17。以 0.10.1 為基礎，只修改安裝程式的舊檔清理。

## 更新後自動清理舊版

以前每次更新都把舊版本移到 `C:\Program Files\Shanjie\versions\.deleted_files`，安裝失敗紀錄留在 `.installer-recovery`，兩者都不會自己減少，多次更新後累積數 GB。

現在更新成功（註冊與檔案校驗完成）後，安裝程式會：

- 永久刪除 `.deleted_files` 內的舊版本。
- 刪除 `.installer-recovery` 內的舊紀錄，只保留這次安裝的一份。
- 舊版檔案仍被 App 載入而刪不掉時，登記為**重新開機時由 Windows 刪除**。

更新失敗時不清理，回復資料照舊保留。解除安裝流程不變，仍把檔案移到 `.deleted_files`。

## 資料與相容性

只改安裝程式；輸入法 DLL、核心、上游 pin、內建模型與 profile schema 都沒有變。個人詞庫、學習資料、Models 與設定位於 `%LOCALAPPDATA%\Shanjie`，不受影響。

已通過清理與重開機刪除順序的單元測試，以及完整打包校驗。第一次更新到 0.10.2 時會一次清掉先前累積的舊版。重開機後確實刪除，尚未在真實系統驗證，列在 TODO。
